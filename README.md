# 🏠 Mini-Airbnb - Plateforme d'Annonces de Logements

## 📖 Présentation

Mini-Airbnb est une application web développée dans le cadre d'un projet pédagogique JavaScript à Ynov Bordeaux.

Inspirée de la plateforme Airbnb, cette application permet de consulter des annonces de logements de vacances, d'accéder à leurs détails et d'effectuer des réservations via une interface simple et intuitive.

L'objectif principal du projet était de découvrir le développement web backend avec **Node.js**, **ExpressJS** et **EJS**, tout en consolidant les bases du JavaScript et de la manipulation de données.

---

## 🎯 Objectifs pédagogiques

* Découvrir le fonctionnement d'un serveur web avec ExpressJS
* Comprendre le routage dynamique
* Utiliser un moteur de templates (EJS)
* Générer dynamiquement des pages HTML à partir de données JavaScript
* Servir des ressources statiques (CSS, images)
* Mettre en pratique les bases du développement web full-stack

---

## 🚀 Fonctionnalités

### 🏡 Consultation des logements

* Affichage de l'ensemble des logements disponibles
* Présentation du titre, du prix et d'une image
* Navigation intuitive vers la fiche détaillée

### 📄 Page de détail

* Informations complètes du logement
* Description
* Localisation
* Nombre de voyageurs
* Prix par nuit

### 📅 Gestion des réservations

* Création d'une réservation
* Affichage des réservations enregistrées
* Suppression d'une réservation

### 🎨 Interface utilisateur

* Design moderne inspiré des plateformes de réservation
* Responsive design
* Navigation simple et fluide

## ⚙️ Installation

### 1. Cloner le projet

```bash
git clone https://github.com/LouLFBV/ProjetB1JS.git
```

### 2. Accéder au dossier

```bash
cd ProjetB1JS
```

### 3. Installer les dépendances

```bash
npm install
```

### 4. Lancer le serveur

```bash
node server.js
```

ou

```bash
npm start
```

### 5. Accéder à l'application

```text
http://localhost:3000
```
